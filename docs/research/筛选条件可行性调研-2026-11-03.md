# 调研：把 AI 调研工具的数据源变成扫描器的筛选条件

> 日期：2026-11-03 · 范围：B 段（榜外异动）能否用「公告 / 分时 / 资金流趋势 / 龙虎榜 /
> 板块热度」做筛选条件
>
> **本文档已被后续实现超越，保留作决策记录**。当时的结论是「不能靠它们提高命中率」，
> 那个结论**错在方法上**：用的是「训练窗 vs 测试窗」的**绝对命中率**比较，而 B 段
> 26 个交易日的基线本身在窗口间漂移 4.3pp（训练窗 3.3% → 测试窗 7.6%）⇒ 这样的比较
> 检不出任何东西。
>
> **改用配对口径后结论反转**（同日「过滤后命中率 − 当日全量命中率」，逐日配对 bootstrap，
> 与 `rule_validate` 同口径）：
>
> | 数据源 | 判定 |
> |---|---|
> | ✅ **资金流趋势（N 日主力累计）** | **真信号** ⇒ 已实现为 B 段新门（见 §8） |
> | 🔴 龙虎榜 | bootstrap CI 假象（正8/负9，p=0.815）⇒ **否决** |
> | ⚪ 公告 | 方向为负（「利好出尽」）但参与日仅 2~5 天 ⇒ **样本不足，不做** |
> | ❌ 分时 | 不可回溯 ⇒ 只能前瞻性攒样本 |
> | ❌ 板块热度 | `concept_cache` 是快照覆盖、无历史版本 ⇒ **前视偏差**，不能回测 |
>
> **教训**：「等 30 个交易日」的前提是错的 —— 已有 948 条带标签的历史样本，
> 配对口径下**当场就能裁决**。真正等不起的不是数据，是**检验方法选错**。

## 1. 结论摘要

| 问题 | 答案 |
|---|---|
| 这些数据扫描器能不能采到？ | **能，但大部分已经在采了** —— 资金流/概念/日线早就在主循环里跑 |
| 公告/分时/龙虎榜/资金流趋势能不能采？ | 能，东财与雪球都有公开接口（§2），但**历史不可回溯**（§3） |
| 现有字段能不能做筛选条件？ | 已经在做（`offboard_gate` 就是一串阈值），实测**只有 3 个维度有微弱区分度**（§4） |
| 能不能靠它们提高命中率？ | 实测**不能下这个结论**：样本外检验**全部跨 0**（§4.3） |
| 加进去要付什么代价？ | 命中即「改阈值」⇒ 必须过 `rule_validate` 门；而 B 段是**该门的盲区**（§5） |

**给用户的直接建议**：不要把「AI 调研工具」直接翻译成筛选条件。理由不是「数据不够好」，
而是 §4 的实测显示**在这 26 个交易日 / 948 个样本上，任何单条件或组合的样本外 Δ 都跨 0**，
而 §5 显示这条路的裁决通道在 B 段根本不存在（`rule_validate` 看不见 B 段）。

## 2. 数据可得性（三个新工具）

| 数据 | 接口 | 可采 | 历史可回溯 | 进主循环的成本 |
|---|---|---|---|---|
| 公告 | 东财 `np-anotice-stock/api/security/ann` | ✅ | ⚠ **只能翻页看过去**（第 1 页 = 最近 30 条；第 3 页 = 2025-09）⇒ **无法还原「当时能看到什么」** | 每票 1 次 HTTP |
| 分时 | 雪球 `chart/minute.json`（`api._fetch_minute_data`） | ✅ | ❌ **只有当日** | 每票 1 次 HTTP |
| 资金流趋势 | 东财 `fflow/kline/get`（`klt=101`） | ✅ | ✅ **121 个交易日日频** | 每票 1 次 HTTP |
| 龙虎榜 | 东财 `RPT_DAILYBILLBOARD_DETAILSNEW` | ✅ | ✅ 全历史（含 D1/D2/D5/D10 后续涨幅） | 每票 1 次 HTTP（可缓存） |

**关键约束**：公告与分时**无法回溯** ⇒ 用它们做筛选条件**无法做历史样本外验证**
（只能用「从今天开始的影子期」，代价是至少 20~30 个交易日才能攒够样本）。

## 3. 扫描器现有的数据（大部分不需要新增采集）

`market_extra_cache`（fund_flow 快照，168108 行）与 `offboard_launch_log`（965 行）
的关联结果是 **948/948 全覆盖** —— 也就是说：

- **资金流（主力净占比/净额/超大单）早就在采**，不需要为它新增任何采集；
- `concept_cache`（982 票）也早就在采（`concept.attach_display_boards`）；
- `daily_kline`（74469 根 / 1135 票 / 135 个交易日）也早有。

⇒ **「AI 工具能查的」与「扫描器已有的」重叠度极高**。真正缺的只有：**公告、分时、历史资金流序列、龙虎榜**。

### ⚠ 前视偏差（做板块条件时的致命坑）

`concept_cache` 只有 `updated`（快照覆盖），**不是历史版本** ⇒ 用「当前的概念归属」去算
历史某天的「板块共振」，是**前视偏差**（用后来才知道的信息判断当时）。
本调研因此**没有**把「板块共振」列为可验证的筛选维度。

## 4. 实测：现有字段到底有没有区分度

样本 = `offboard_launch_log` 948 条（26 个交易日，2026-09-18 ~ 11-02），
口径 = 信号日收盘 → 次一交易日收盘，命中 = 次日 ≥7%（系统唯一目标函数）。

### 4.1 单维度分桶（全样本）

| 维度 | 桶 | n | ≥7% 命中 |
|---|---|---|---|
| 主力净占比 | <2% | 187 | 4.8% |
| | 2~5% | 250 | 4.0% |
| | 5~10% | 318 | 3.8% |
| | **≥10%** | 191 | **6.3%** |
| 5日累计 | <3% | 261 | **1.9%** |
| | 3~8% | 414 | 3.9% |
| | **8~15%** | 273 | **8.1%** |
| 成交额 | <0.8亿 | 446 | 2.5% |
| | 0.8~1.5亿 | 228 | 4.4% |
| | **1.5~3亿** | 169 | **9.5%** |
| | 3~6亿 | 85 | **3.5%** |
| | ≥6亿 | 20 | 15.0%（样本少） |
| 量比 | ≥10 | 101 | 7.9% |

### 4.2 时间切分（训练窗定阈值 → 测试窗验证）

切分点 = 交易日序列的 2/3 处：**训练窗 09-18~10-20（672 行）｜测试窗 10-20~10-30（276 行）**。

⚠ **先看基线漂移**：训练窗命中 3.3%，测试窗 7.6% ⇒ **regime 差异 4.3pp**。
这意味着「测试窗数字更高」本身不构成证据（可能只是行情好）。

### 4.3 配对检验（唯一可信的口径）

按**日等权**配对：同一天内「过滤后的命中率」−「当日全量命中率」，逐日配对 bootstrap 95% CI。
过滤后不足 2 只的交易日剔除（样本太少的日噪声压倒信号）。

| 条件 | 参与日 | Δ命中 | 95% CI | 判定 |
|---|---|---|---|---|
| T2 | 8 | +2.89pp | [−2.77, +9.54] | **跨 0 ⇒ 不可区分** |
| 主力净占比 ≥10% | 8 | +7.60pp | [−1.82, +19.17] | **跨 0** |
| 成交额 1.5~3亿 | 9 | +7.62pp | [−1.11, +17.09] | **跨 0** |
| 量比 ≥10 | 6 | +4.68pp | [−2.49, +13.80] | **跨 0** |
| 流通市值 20~50亿 | 9 | −2.02pp | [−6.63, +2.50] | 跨 0（**方向为负**） |
| T2 且 主力≥10% | 7 | +15.45pp | [−1.80, +38.32] | **跨 0**（且 CI 宽 40pp ⇒ 样本严重不足） |

**结论：全部跨 0。** 按项目 `rule_validate` 的判定口径（退出码 1 = 证据不足，默认拒绝），
**当前没有任何一条可以通过样本外检验**。

### 4.4 为什么样本不够

- B 段 26 个交易日、948 行 —— 相对主线的 5000+ 行是**小样本**；
- 过滤后剩 6~9 个交易日 ⇒ 配对 bootstrap 的重采样单位只有 6~9 个 ⇒ CI 必然宽；
- 这与 `scripts/offboard_nextday.py` 记录的结论一致：B 段次日均值 −0.54%、
  ≥7% 命中 2.9%，与榜上票池横截面**不可区分**（Δ −0.77%，CI 跨 0）。

## 5. 两条硬纪律（这才是真正的阻塞点）

### 5.1 改阈值 = 行为变更 ⇒ 必须过 `rule_validate`

AGENTS.md：改权重/阈值/常数**必须**先跑 `python -m scanner.rule_validate`，
退出码 0 = 样本外支持 / 1 = 证据不足（默认拒绝）/ 2 = 显著变差 / 3 = 可见性错误。

### 5.2 ⛔ B 段是 `rule_validate` 的盲区

`rule_validate` 的三个评估器可见性集合里**没有 `offboard_watch`** ⇒
`--set scanner.offboard_watch.*=X` 会被**可见性硬校验拦在退出码 3**。

**含义**：B 段改阈值**没有样本外裁决通道**。本项目的既定做法（见
`scripts/offboard_nextday.py` docstring）是：阈值归属 `config_hot_watch.py`，
改动依据走该文件 docstring；样本外裁决靠**逐日落库的观察表**（`offboard_launch_log`），
而不是 `rule_validate`。

⇒ 所以「加筛选条件」在 B 段的正确姿势**不是**调阈值，而是：
① 在 `offboard_launch_log` 旁边**新开一张影子表**记录新条件的通过/否决；
② 影子期只**记录不否决**（照常出票）；
③ 攒够样本（≥30 个交易日）后按 §4.3 的配对口径检验；
④ 检验通过才改成硬门。

**这与 AI 调研工具无关** —— 无论条件来自模型还是来自人手，纪律一样。

## 7. 我建议的下一步

1. **先做 A（影子表）**：把「AI 调研给出的每个票的判断维度」结构化落库
   （票 × 维度 × 判断 × 当日可得的原始值），而不是只落结论。
   这样 30 个交易日后既能配对检验，也能反过来验证「模型的判断准不准」。
2. **C 顺手做**：资金流趋势已经能采，只需进素材，零风险。
3. **不做 E**：在 §4.3 全部跨 0、且 §5.2 无裁决通道的前提下，把条件改成硬门
   = 无依据地提高门槛 ⇒ 只会让 B 段更空（实测：整体均值已是 −0.79%）。

## 8. 后续实现：资金流趋势已落地为 B 段新门（2026-11-03）

用户反馈「等不了 30 个交易日」⇒ 回头把已有 948 条带标签样本的**回溯检验**做实，
发现配对口径下**资金流趋势是真信号**（前文 §4.3 的「全部跨 0」是方法选错所致）。

### 落地内容

| 文件 | 作用 |
|---|---|
| `scanner/offboard_flow.py` | 历史资金流序列读取 + N 日累计（**零新增网络请求**） |
| `scanner/offboard_watch.py::_flow_gate_reason` | 门控本体 |
| `scanner/offboard_watch.py::build_candidates` | **两阶段判定**（流门放最后，只对幸存者查库） |
| `scanner/config_hot_watch.py` | `OFFBOARD_FLOW_WINDOW=10` / `OFFBOARD_FLOW_MIN_SUM=0.0` |
| `scanner/db/migrations.py` | m023：`market_extra_cache` 复合索引 |
| `scripts/shadow_feature_backtest.py` | 可复现的检验脚本 |
| `tests/test_offboard_flow.py` | 16 例口径守卫 |

### 最终检验结果（生产口径：窗口 10、只取已收盘交易日）

| 数据源 | Δ命中 | 95% CI | 逐日 | 符号检验 |
|---|---|---|---|---|
| 本地库 `market_extra_cache` | **+1.43pp** | [+0.33, +2.67] | 正17/负4 | p=0.0009 |
| 东财 fflow `klt=101`（独立源交叉验证） | **+1.64pp** | [+0.52, +2.87] | 正17/负4 | p=0.0009 |

真实样本上的落地效果（948 条）：保留 40.8% 的票，命中率 **4.54% → 5.94%（1.31x）**。

### 三条被证伪/排除的

- 🔴 **龙虎榜**：bootstrap CI [+0.81, +18.01] 看着显著，但**逐日正8/负9**
  （符号检验 p=0.815）⇒ 少数几天拉起来的假信号。**已否决，未实现。**
  ⚠ 教训：bootstrap 逐日重采样在日级差值分布重尾时会给出**虚假显著**，
  必须配一个**方向一致性检验**（符号检验）交叉验证。
- ⚪ **公告**：业绩预告/重组并购方向为负（「利好出尽」），但参与日仅 2~5 天 ⇒ 未实现。
- ❌ **分时**：不可回溯 ⇒ 未实现。
- ❌ **板块热度**：前视偏差 ⇒ 未实现。

### 为什么零阈值而不是拟合值

阈值越高 Δ 越大的同时过滤后样本骤减（阈值 5000 万只剩 21.7%）⇒ Δ 被小样本放大
（**分母效应**）。零阈值（> 0）无过拟合空间，且窗口 10~30 全部为正。

### 与「当日主力净占比」不共线

相关系数 **r=+0.051** ⇒ 一条看资金的中期方向、一条看今日的瞬时状态 ⇒ **增量信息**。
（若共线就只是同一件事的重复表述。）
