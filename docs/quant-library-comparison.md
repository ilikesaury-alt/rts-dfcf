## 二、当前项目能力现状（rts-dfcf）

- **数据源**：雪球（飙升榜/热搜榜/批量行情/日K/分时）、东财 F10 概念、AKShare 兜底。**无** tushare/baostock/问财、**无**财务、资金流、龙虎榜、新闻
- **指标**：手写 RSI/KDJ/MACD/ADX/ATR/BOLL/OBV/MA，**无** TA-Lib、筹码分布、完整形态库（仅 6 种）
- **选股**：5 策略并行 + 多因子加权评分（10+ 增强 bonus + RPS + 情绪周期 + 双重交叉验证）——规则型多因子，**无**统计/ML 拟合
- **回测**（`scanner/backtest.py`）：**信号归因型**（胜率/均收益/盈亏比/逐维度 rank-IC），**无**组合模拟、佣金滑点、Sharpe、最大回撤、基准对比、walk-forward
- **风控**：7 种堆叠风险标签 + 2 个硬过滤（主力出货/趋势破位）
- **组合/仓位/交易**：完全无
- **可视化**：终端 TUI + 飞书卡片 + `stock_report.py` 报告，**无** Web UI/图表库
- **ML/参数优化/新闻舆情**：均无

## 三、缺失功能对比清单（按重要性排序）

| # | 缺失/薄弱项 | 参照库 | 本项目现状 | 缺失程度说明 |
|---|---|---|---|---|
| 1 | **基本面/财务数据与筛选**（PE/PB/ROE/营收增长/股息/财务质量） | akshare, tushare, InStock, jqdatasdk | **完全无**——仅市值/价格/ST 硬过滤 | 最严重。所有主流选股库的"基本面筛选"维度在本项目是空白；目前纯技术面+榜单动量，无法做价值/质量/成长维度 |
| 2 | **完整组合回测引擎**（T+1 结算、佣金/印花税/滑点、基准对比、Sharpe/最大回撤/净值曲线/多策略对比） | backtrader, rqalpha, vectorbt, akquant | 仅信号归因（IC/胜率），**无执行现实性模拟** | 高。现有 `backtest.py` 只能回答"这策略过去准不准"，无法回答"实盘资金跑下来收益/回撤多少"，策略调优缺乏资金曲线依据。**→ 2026-08-07 已实现**：`scanner/portfolio_backtest.py`（等权满仓旋转、A股真实成本、基准对比、Sharpe/最大回撤/净值曲线、多策略对比），见下结论。 |
| 3 | **资金流向/龙虎榜/涨停原因/新闻资讯等行情增强数据** | akshare, tushare, InStock | 无（分时资金流代码明确标注不可用） | 高。雪球接口覆盖度有限；主流工具都集成这些，用于确认主力行为和事件驱动，是选股增强的核心数据源 |
| 4 | **因子分析工具链**（IC 衰减、分位数分组收益、alpha 因子换手率、tear sheet；组合绩效指标） | alphalens, quantstats, pyfolio | 仅有逐维度 rank-IC | 中高。已有 IC 雏形，缺分位数/衰减/换手/风险指标；这是从"手工调参"走向"数据驱动调参"的关键一步 |
| 5 | **筹码分布 + 完整 K线形态库**（61 种）+ 指标标准化 | InStock, TA-Lib, pandas-ta | 手写 12 个指标 + 6 种形态，纯 Python | 中。指标对撞（形态/筹码）是 InStock 核心卖点，本项目手写实现覆盖面窄且慢 |
| 6 | **参数自动优化**（网格/贝叶斯搜索） | freqtrade hyperopt, akquant grid, vectorbt | 无自动化优化器（靠 IC 报告手动调） | 中。当前调参流程慢，5 策略 × 数十权重，人工枚举不可行 |
| 7 | **ML/AI 因子建模**（监督学习/时序模型/walk-forward） | qlib, PyBroker | 无 | 中（锦上添花）。规则型策略已自洽，ML 引入需大量因子样本，收益不确定 |
| 8 | **Web UI / 图表可视化**（K线图、收益曲线、盘中监控面板） | InStock, vnpy, KHunter | 仅终端 TUI + 飞书 | 中低。影响使用体验但非核心算法能力 |
| 9 | **自然语言选股**（中文问句直接出筛选结果） | pywencai | 无 | 低。可作为互补工具而非替代 |
| 10 | **组合管理/仓位/实盘对接**（订单、持仓、券商接口） | vnpy, rqalpha | 无 | 视定位而定：作为"信号推荐器"不缺失；若想自动交易则升级为最高优先级 |

## 结论

本项目最强的部分是**盘中实时微观结构分析**（分时强度、早盘量比投影、榜单动量、双源交叉验证）和**规则型多因子评分体系**——这是 InStock/KHunter 等选股系统普遍没有的。

最薄弱的三大块是**基本面数据维度（#1）**、**组合级回测（#2，已于 2026-08-07 实现 `scanner/portfolio_backtest.py`）**、**行情增强数据（#3）**，建议优先补齐；其余为渐进增强。
