# 沪深飙升区扩容设计 —— 榜外候选段（B 段）

> 2026-09-18 · 调研 + 实测驱动 · **本文档只做设计，未改任何生产代码**
> **范围：只针对「沪深飙升」区**（不新增区、不改该区列定义）
>
> 一句话：**不改区、不改列**，给「沪深飙升」区补一路**榜外候选来源** —— 用项目已在手但从未被消费的
> 全市场快照 + 一次 ~50s 的榜外 K 线补取，把 313 只榜外创业板纳入该区的 **B 段**；分两层：
> **T1「量先动·价未动」**（真正的提前）与 **T2「启动首日」**（口径完全复用既有 `MOMENTUM_LAUNCH_*`）。

## 1. 调研结论

### 1.1 有实证支撑的（机构研报）

| 来源 | 结论 | 其口径 | 能否直接搬 |
|---|---|---|---|
| 华泰《单因子测试之资金流向因子》(2018) | 8 类资金流因子中 4 类有效；**开盘主力净流入率**最优（IC>0 占比 81.05%、IR 0.78、多空年化 14.71%） | 月频·全A·10日持有 | ❌ 我们拿不到「开盘时段」切片 |
| 同上（残差分析） | 资金流因子对动量/换手/波动做残差后**仍有增量信息** | 同上 | ✅ 支持「主力净占比」作独立维度 |
| 华泰《单因子测试之换手率类因子》(2017) | 换手率因子**5 天左右短样本期最优**（动量类要 21~33 天） | 月频 | ✅ 支持短窗设计 |
| 华泰《A股择时十大技术指标》(2026) | 「60日换手率波动」多头端有效，机制解释：**量能领先于价格** | 指数择时 | ✅ 支撑「量先动」的核心假设 |
| 东吴金工（转引） | 传统换手率因子 2006–2021 全A 年化 **ICIR −2.10**（高换手→未来收益低），多空对冲年化 33.41% | **月频·全市场** | ⚠️ **方向相反，不可直接搬** |

**关键裁决 —— 换手率的符号冲突**：东吴的负向结论是**月度截面、多空对冲**口径；本项目目标是
**次日 ≥7% hit**。两者时间尺度差约 20 倍，符号翻转是常态。项目自己的实证已给出次日尺度的答案：
「低吸规则里的缩量是负向的」（09-16，2691 样本，**缩量 vr<0.8 hit 4.3% < 平量 8.1% ≈ 放量 7.7%**），
即**放量在次日尺度上是正向的**。
⇒ **采信次日尺度；同时明确：量比/换手率的正负号必须在本项目数据上重新校准，不得引用研报数字。**

### 1.2 只有社区口碑、无实证的（降级为「候选特征」，全部标注待校准）

- 量比分档：1.2–2.0 温和放量 / 2.0–5.0 「涨停高发区间」/ >5 需结合位置
- 换手率 5%–10%「黄金区间」；>20% 视为高位出货
- 流通市值 50–200 亿「优选」（太小易闪崩、太大难撬动）
- 「成交量要温和堆量，拒绝脉冲式爆量」
- 「分时全程站稳均价线 + 强于大盘」

⚠ 这批内容**互相转引、源头不可溯源**（多为自媒体），只能当**待验证特征清单**，
**不可作为阈值依据**。其中「换手率 5–10%」与本项目实测直接冲突（见 §2）。

## 2. 实测约束（榜外画像，2026-09-18 11:18 实盘快照）

| 指标 | 榜外创业板（过通用门 313 只） | 含义 |
|---|---|---|
| 换手率 p50 | **1.00%** | 「5–10% 黄金」在榜外仅覆盖 **6/264**，该口径**不可移植** |
| 换手率 <3% | **244/264（92%）** | 榜外主体是**冷票** |
| 流通市值 p50 | **25 亿**（p25=16，p90=57） | 普遍小微盘；「50–200亿优选」同样不适用 |
| 涨幅 3–7% ∧ 量比≥1.5 | **23 只** | 全局唯一有点量感的交集 |
| 量比 ≥3 | **仅 6 只** | 榜外极少剧烈放量 |

**⇒ 两个结论**
1. 榜外**不是**「换手活跃的启动票」，而是「**冷门低换手小微盘**」；现有研报与社区阈值**整体不可移植**。
2. **必须新增流动性下限门**，否则候选会全是不可成交的壳票。

### 2.1 三项能力实测（决定性）

| 能力 | 实测 | 结论 |
|---|---|---|
| 全市场快照 | 5305 行 / 54 页 / **17.4–28.8s**（波动大） | 已在跑，无需新增请求 |
| **榜外补 K 线** | **313 只 / 8 并发 / 49.6s / 0 失败** | ✅ **可落地**（放非交易时段） |
| **两源量比一致性** | clist `f10` p50=**1.21** vs K线计算 p50=**1.21** | ✅ 快照量比**可直接用**，量比不依赖补 K 线 |

最后一条很重要：它把「量比」从 K 线依赖里解耦出来，意味着**即使补 K 线失败，T1/T2 的
主键信号仍然可用**（降级为只用量比 + 资金流）。

## 3. 信号设计

### 3.1 数据通路（三条，全部已在手或已实测可行）

1. **`market_extra_cache` 全市场快照**（09-18 已扩字段）：价 / 涨幅 / 量比 / 换手 / 成交额 /
   流通市值 / 主力净占比 / 超大单 —— 零额外请求，每 300s 已在拉。
2. **榜外 K 线池（新建，独立于 `daily_kline`）**：5 日累计涨幅、MA 结构、顶背离判定。
   🔴 **不得写入 `daily_kline`** —— 该表的既定语义是「榜单衍生池」，塞入榜外票会污染
   所有基于它的回测基准与归因（`portfoliobacktest` / `prevday_perf` / 召回率口径）。
3. **通用风险门** `display_gates.common_hard_gate`（8 道，复用单源实现）。

### 3.2 门槛

- **通用 8 门**：直接复用 `display_gates.common_hard_gate`（ST / 样本面 / 状态 / 报价 /
  量 / 价格≤200 / 市值≤500亿 / 资金流出≤−8%）。
- **榜外专属新增门（方向 = 收紧，符合「区域可收紧不可放宽」契约）**：

  | 新增门 | 初值 | 依据 |
  |---|---|---|
  | 成交额下限 `OFFBOARD_MIN_AMOUNT` | **3000 万** | 实测 T1/T2 的 p50 落在 4500–16400 万，故该值很宽松；太冷的票无法成交 |
  | 流通市值下限 `OFFBOARD_MIN_FLOAT_CAP` | **10 亿** | 实测 T2 最低 14 亿；避开壳票/闪崩 |

  理由（调研明确警示）：成交额极低的冷门小盘，**少量资金即可操纵分时，指标本身没有参考价值**。

### 3.3 分层（这是「提前」的落点）

| 层 | 条件 | 语义 |
|---|---|---|
| **T1 量先动·价未动** | 5日累计 ∈ [0,7) ∧ 今日涨幅 ∈ (0, 3.5) ∧ 量比 ≥ 1.5 ∧ MA 非空头 ∧ 主力净占比 ≥ 0 | **真正的提前**：量起来了、价还没起、且是买入量 |
| **T2 启动首日** | 5日累计 ∈ [0,7) ∧ 今日涨幅 ∈ [3.5, 8] ∧ 量比 ≥ 1.5 ∧ MA 非空头 ∧ 无顶背离 | **口径复用既有 `MOMENTUM_LAUNCH_*`** |
| 排除 | 今日 >8% / 5日累计 ≥7% / 今日 ≤0 | 不追高、不接跌 |

T2 的五个阈值**直接 `import` 自 `config_scoring`**（`MOMENTUM_LAUNCH_ACCUM_MIN/MAX`、
`MOMENTUM_LAUNCH_TODAY_MIN/MAX`、`MOMENTUM_LAUNCH_VOL`），**不新增同名常量** ——
项目铁律：口径不得复制（守护 `test_category_priors.py` 同类思路）。

T1 与 T2 的分界取 **3.5%** 正是既有 `MOMENTUM_LAUNCH_TODAY_MIN`：低于它 = 「价还没动」，
高于它 = 「已启动」。这样 T1 不是新发明的语义，而是**既有启动定义的下沿延伸**。

### 3.4 排序键 —— 以及「不能混排」的硬理由

**现状**：飙升区已有复合分 `rank_change 35 / percent 25 / price 15 / 量能 25`（合计 100）。
榜单专属项 `rank_change` 独占 **35 分**，而榜外票**结构上没有这个量**（恒为 0）⇒
若把榜外票直接并入同一排序，它们会**固定丢掉 35 分、被永久压到最末**。
这不是「口径不可比」的抽象说法，而是**具体的 35/100 结构性缺失**。

⇒ **同区内分两段并列，不混排**（与项目「不跨区排名」铁律同源）：

| 段 | 候选来源 | 排序键 |
|---|---|---|
| **A 榜内飙升**（现状完全不变） | `xq_raw` 榜单 | 既有 `compute_score`（含 rank_change 35） |
| **B 榜外异动（新增）** | 全市场快照里的榜外创业板 | `(−量比, −主力净占比)` |

- B 段主键 = **量比**。机制依据：量比 = 当日每分钟均量 ÷ 近 5 日每分钟均量，是「**增量资金**」的
  直接代理；华泰择时报告给出「量能领先于价格」的解释。
- B 段第二键 = 主力净占比：华泰残差分析显示资金流因子对量价因子有**增量信息**。
- B 段**不引入复合权重**：项目已证复合排序在无标签时必然过拟合（推荐池 `score` 排序 AUC 0.469）。

### 3.5 产出宽度（实测）

- **B 段：T1 = 5 只、T2 = 4 只，合计 9 只**（2026-09-18 11:18 实盘）⇒ 取 top 5 与 A 段体量一致。
- A 段维持现状（`HOT_DISPLAY_TOP` 上限不变）。
- 两段合计新增最多 5 行 ⇒ **不会造成展示爆炸**。

## 5. 可验证性设计（不可跳过）

1. **逐日落库**：`(date, symbol, tier, 各信号原始值, next_day_pct)` —— 必须先有数据才谈阈值。
   现状是 `hot_watch_hits` 以 symbol 为主键、只存滚动最新态，**本类产出从未被回溯量化**，
   这是任何新信号上线前唯一的硬前置。
2. **影子期**：建议先 **4~6 周只落库**（展示可以不进主表），攒够按日样本。
3. **验收标准**（借 WorldQuant-101 的门槛，改造成本项目的口径）：
   - 按日等权 top-N 次日 hit 率 vs 全市场基线 **6.1%**
   - 样本 **≥ 50 期**；\|Δ\| 需超过 MDE；**翻转天数 > 0**
   - 类别先验若入主表，须补进 `config_scoring.CATEGORY_HIT_RATE`（唯一手抄源）
4. **不要做的事**：在没有标签的情况下调阈值 —— 项目铁律 observe-first。

## 6. 风险与诚实边界

| 风险 | 说明 |
|---|---|
| **无历史背书** | 榜外信号**从未被回测**。T2 的常量是在**榜上**样本校准的，域迁移（榜外）不保证成立 |
| **量比时段失真** | 项目 `_compute_volume_metrics` 已有**早盘量能投影**处理（按已交易分钟投影全天）；但快照 `f10` 是交易所口径，实测中位与 K 线口径一致（1.21 vs 1.21），仍建议在 09:35–09:45 窗口复核 |
| **容量极小** | 榜外 p50 换手 1.0%、市值 25 亿 ⇒ 即使信号有效，**实盘容量与滑点都是硬约束** |
| **补 K 线扩大漂移面** | 新增 ~313 只票的 K 线，前复权重算会扩大 `kline_drift` 监控面 |
| **快照耗时波动** | 17.4–28.8s，且是「首轮 ~20s 冷启动」的来源；**不可再加并发**（实测 6→16 线程无收益） |
| **榜单依赖被解开** | 本区不再依赖 `xq_raw`，因此**雪球榜单挂掉时本区仍可产出** —— 这是附带收益，但也意味着它**不受既有榜单熔断保护**，需独立降级 |

## 7. 实施步骤（建议顺序）

1. **榜外 K 线池**：新建独立表 + 日更任务（**不碰 `daily_kline`**），并接入既有 `kline_drift` 锚定

6. （可选）T1 的「主力净占比 ≥ 0」等加严项做敏感性分析

## 8. 一页速查

| 项 | 值 |
|---|---|
| 范围 | **只改沪深飙升区**（不改区、不改列、不新增区） |
| 段 | A 榜内飙升（现状完全不变） / **B 榜外异动（新增）** |
| 候选面 | 榜外创业板，过通用门 **313 只** |
| 新增门 | 成交额 ≥3000万、流通市值 ≥10亿（区域收紧，显式传参） |
| T1 | 累计∈[0,7) ∧ 今日∈(0,3.5) ∧ 量比≥1.5 ∧ MA非空头 ∧ 主力净占比≥0 → **5 只** |
| T2 | 累计∈[0,7) ∧ 今日∈[3.5,8] ∧ 量比≥1.5 ∧ MA非空头 ∧ 无顶背离 → **4 只** |
| B 段排序 | `(T1<T2, −量比, −主力净占比)` |
| 不混排理由 | A 段分含 `rank_change 35/100`，榜外票恒缺 ⇒ 混排必被压末 |
| 主键依据 | 量比 = 增量资金代理；「量能领先于价格」 |
| 展示 | 同区 B 段，top 5，无操作建议，不下 `recommendations` |
| 前置 | 逐日落库 + 影子期 ≥50 期 |
