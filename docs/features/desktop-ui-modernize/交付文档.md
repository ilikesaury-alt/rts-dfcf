# 桌面版 UI 现代化 · 交付文档

| 项 | 值 |
|---|---|
| 功能名称 | 桌面版面板 UI 现代化（设计系统 + 导航 + 分栏 + 只读图表） |
| 面向对象 | 使用桌面版看板的用户（本人盯盘 / 复盘） |
| 影响范围 | **仅桌面版/Web 面板的外观与交互**；终端输出、飞书卡片、扫描逻辑、评分与阈值**零变化** |
| 本版本不包含 | 交易下单、提醒、账号体系、任何新增筛选/排序/判断；板块热力图；自定义标题栏（见「已知问题与后续」） |

---

## 1. 功能概述

把原先「一页长滚动 + 手写样式」的桌面看板，升级为带**侧边区块导航**、**可拖拽分栏**、**卡片化区块**、**冻结首列表头**与**本轮计数图**的现代看板。

所有数据仍来自本机扫描器的最后一轮，面板依旧是**只读镜像**：不新增筛选、不新增排序、不新增任何结论。本次改的是「怎么看」，不是「算什么」。

---

## 2. 使用说明

### 2.1 入口
- 桌面版：双击桌面版应用（Electron 壳 → 自动拉起本机扫描器 → 加载看板）。
- 浏览器：`http://127.0.0.1:8899/`（扫描器以 `RTS_LOCAL_PANEL=1` 运行时）。
- 命令行扫描器的终端输出**完全不变**（本次未触碰终端渲染）。

### 2.2 界面构成

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶部状态条：标题 · 本机只读 · 轮次时间/seq/时段 · 数据滞后告警        │
├──────────┬───────────────────────────────────┬───────────────────┤
│ 侧边导航  │  主区（区块卡片，可纵向滚动）        │  右侧栏（可拖宽）   │
│ (可折叠)  │  ◆ v1 池选                        │  本轮计数          │
│          │  ◆ v1 回捞                        │   通过门的档位分布   │
│ v1 池选  │  ◆ 沪深飙升 · 极有可能大涨          │   各区块只数        │
│ v1 回捞  │    — 榜内飙升                      │   ◆ 飞书过门        │
│ 沪深飙升 │    — 榜外异动                      │    门内/门外 切换   │
│ 飞书过门 │                                   │    7 项账目         │
├──────────┴───────────────────────────────────┴───────────────────┤
│ 页脚：只读视图 · 不新增筛选/排序/判断 · 数据来源 · 轮询间隔           │
└──────────────────────────────────────────────────────────────────┘
```

### 2.3 操作方式

| 操作 | 效果 |
|---|---|
| 点侧边导航项 | 平滑滚动到对应区块（导航顺序 = 区块在页面里的物理顺序） |
| 点侧边 `«` / `»` | 收起 / 展开侧边导航（收起后显示两字缩写，点一下即展开并跳转） |
| 拖动主区与右栏之间的分隔条 | 调整主表格区与右栏宽度；**宽度会被记住**，下次打开保持 |
| 横向拖动表格 | 表头固定在上方、`#` 列固定在左侧，滚动时不丢失列含义 |
| 点任意一行 | 进入个股详情页（K 线 + 评分分解 + 出现史） |
| 详情页点「← 返回列表」 | 回到看板首页 |
| 过门区「门内 / 门外」 | 切换看「下一张卡会推的票」/「本轮不会推的票」，标题不变 |

### 2.4 各区域含义（**未改，仅换样式**）

- **◆ v1 池选**：主榜单，排序键为「新票优先·类别优先·排名升序·资金流降序」（由扫描器决定，面板不重排）。
- **◆ v1 回捞**：前若干交易日进过 v1、今日回调到位的票，与上方口径独立。
- **◆ 沪深飙升 · 极有可能大涨**：两段并列、互不排名 ——「榜内飙升」与「榜外异动」。榜外异动段是观察段，**未经回测**。
- **本轮计数**（新增）：用已有数据画的两张只读图 ——「通过门的档位分布」与「各区块只数」。**只回答「有多少只」，不回答「哪只更好」**。
- **◆ 飞书过门**：展示**下一张飞书卡会推什么**（不是已经推过的内容）。卡片最多 5 分钟才推一次且只在集合变化时推，所以这里看到的是「将要推的集合」。

### 2.5 颜色口径（未改）

红涨绿跌（A 股口径，与欧美相反）：涨 `#ef232a`，跌 `#14b143`。行尾标记含义同终端：`新`（本轮新进池）/ `⚡`（动量加速）/ `稳`（日线美感）/ `▼▼`、`▼`（主力净流出警示）。空数据一律显示 `—` 或 `—（本轮无数据）`，不显示 `0`。

## 3. 权限 / 配置变更

**无。**

- 未新增任何权限点、角色、账号体系。
- 未新增任何扫描器阈值、权重、常数（本次零 Python 改动）。
- 数据契约（上报载荷 `SCHEMA_VERSION`）**未变**，仍为 2；未新增/删除任何接口字段。
- 唯一新增的是**前端构建依赖**（Tailwind、shadcn 组件原语、分栏与图表库），只影响打包体积，不影响运行时行为。

## 5. 已知问题与注意事项

1. **构建体积变大**：主 JS 约 371KB（gzip 约 118KB），图表库已单独拆包并懒加载（330KB，gzip 约 99KB），首屏不会等它。看板是本地回环页面，无网络传输成本。
2. **`@tailwindcss/vite` 需要 pnpm12 的构建许可**：本机 `web/pnpm-workspace.yaml` 已有 `allowBuilds: esbuild: true`；Tailwind v4 的原生二进制以预编译形式分发，**不需要**额外 postinstall，实测无需新增键。若在别的机器上 `pnpm install` 后构建失败，先查 `allowBuilds`。
3. **非交易时段无新轮次**：闭市后扫描器不再产出新轮，面板会持续显示最后一轮，状态条提示「非交易时段」；若超过一个刷新间隔未更新，会显示「数据滞后 N 轮」——这是**预期行为**，不是故障。
4. **「本轮计数」是纯展示**：它只统计已有数据的只数，**不构成任何倾向性判断**；若看到图表与过门区数字不一致，以过门区 7 项账目为准（图表用的是区块行数，过门用的是门的账目，两者口径不同）。
5. **窄屏未实测**：≤900px 的堆叠约束已保留等价实现，但本次未在手机/小窗上实测；桌面版最小窗 900×600 可用。
6. **预存在的失败测试**（与本次无关）：`tests/test_data_health.py` 3 项与 `tests/test_rule_tracking.py` 3 项在本次改动前的干净树上同样失败（已用 `git stash` 验证）。若在 CI 看到这 6 项红，不要归因于本次改动。

## 6. 部署与回滚要点

### 部署
1. `cd rts-panel-cloud/web && pnpm install && pnpm build`（生成 `web/dist`）。
2. 桌面版：`cd desktop && pnpm run dist`（其 `prepare.mjs` 会先校验 `web/dist/index.html` 与自带解释器）。
3. 运行期无需改任何 `.env` 键；扫描器侧无需重启配置。

### 回滚
- **整体回滚前端**：`git revert` 本次前端提交即可（`styles.css` 会随 revert 恢复）。Python 侧零改动，回滚不影响扫描/飞书/终端。
- **仅回滚某个视觉特性**：本次改动按 4 个垂直切片提交，可按切片单独 revert。
- **临时关闭图表**（若某环境下 Recharts 异常）：把 `App.tsx` 里 `lazy(() => import("./components/StatsCharts"))` 改为不渲染即可，其余功能不受影响。
- **回滚不影响数据**：本次未写库、未改契约、未改任何阈值，回滚无数据迁移成本。
