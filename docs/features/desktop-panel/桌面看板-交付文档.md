# 桌面看板（RTSPanel）交付文档

> 版本：2026-10-19（commit `e651fff` + 审查修复）。规格见 `docs/desktop/CONTEXT.md`，
> 实施记录见 `docs/desktop/IMPLEMENTATION.md`（本篇面向使用者，不重复实现细节）。

## 1. 功能概述

把扫描器的终端面板装进一个**本机桌面窗口**（Electron），数据与终端完全同源
（同一份 `serialize_view` 输出），只读、仅本机（`127.0.0.1`），不依赖公网。
面向使用者本人：不开终端也能随时看到 池选 / 沪深飙升（榜内飙升·榜内异动·榜外异动）/ 过门区，
点行可进个股详情（K 线 + 评分分解 + 出现史）。

**本版本不包含**：「榜内异动」段暂不进桌面契约（已拍板，见实施记录 §7）；macOS 打包；云端面板改动。

## 2. 使用说明

三种跑法（任选）：

| 跑法 | 操作 | 适用 |
|---|---|---|
| 只开本地看板（无窗口，浏览器访问） | 设 `RTS_LOCAL_PANEL=1` 后照常跑 `python unified_scanner.py`，浏览器开 `http://127.0.0.1:8899/` | 已有终端在跑，只想补个网页视图 |
| 开发态桌面窗口 | `cd desktop && pnpm install && pnpm start` | 改前端/壳代码时 |
| 打包 exe | `desktop/dist/win-unpacked/RTSPanel.exe`，双击 | 日常使用 |

- 换端口：设 `RTS_LOCAL_PANEL_PORT`（脏值/越界自动回退 8899，两端口径一致）。
- 状态条显示「轮次 · seq · 早盘/收盘」；数据滞后超阈值时橙字提示「数据滞后 N 轮」；首轮扫描完成前显示「等待扫描器首轮上报…」，不会白屏。
- 过门区标题是「下一张卡会推什么（非已推内容）」——它展示的是待推送集合，不是推送历史。
- 终端扫描器照常跑，只是多一行「🖥 本地看板: …」；关 `RTS_LOCAL_PANEL`（缺省即关）行为与改前完全一致。

## 3. 权限 / 配置变更

- **无新增权限点、无角色系统**（单机单用户工具）。
- 网络面：本地 HTTP 服务只绑 `127.0.0.1`，不可被同网段访问；无 env 覆盖绑定地址的路径。
- 打包态新增配置落点：`%APPDATA%\rts-desktop\`（`scanner.db` 冷快照首次种入、`logs/`、`.env` 需手动拷一份过去——**密钥不进包**）。
- 可用环境变量：`RTS_PYTHON`（指定解释器）、`RTS_DB_PATH`（与终端共用一个库时设）、`RTS_LOG_DIR`、`RTS_DESKTOP_SCANNER_ARGS`（调试用，日常不用）。

## 4. 测试指引

| # | 用例 | 预期 | 覆盖方式 |
|---|---|---|---|
| 1 | `RTS_LOCAL_PANEL=1` 跑扫描器，浏览器开 8899 | 四区块与终端同轮数据一致（池选/飙升/过门逐行对得上） | 手工抽查（自动化只保列结构同源） |

| 4 | 桌面窗口打开后关窗 | 窗口关、子进程退出、8899 释放（任务管理器无残留 python/electron） | 手工实测 2026-10-19；自动化保结构守卫 |

| 6 | 设 `RTS_LOCAL_PANEL_PORT=abc` 后开桌面壳 | 两端都回退 8899，窗口正常打开 | 代码口径一致 + Python 侧有自动化；Node 侧为结构守卫 |

## 5. 已知问题与注意事项

- **桌面版比终端少一段**（榜内异动）：已知且接受的取舍，不是遗漏（`SCHEMA_VERSION` 保持 2）。
- **打包态的库与终端分家**：桌面版写 `%APPDATA%\rts-desktop\scanner.db`，与仓库根 `scanner.db` 各记各的；想共用启动前设 `RTS_DB_PATH`。
- **双击 exe 会接管扫描器**：单实例语义是「杀掉更旧的实例」，会把正在跑的终端扫描器结束掉（既有行为，非壳引入）。想并存：先开 exe，再在终端跑 `RTS_DESKTOP_SCANNER_ARGS="--no-lock --no-feishu"` 联调，或干脆只用其一。
- **`.env` 不进包**：首次使用把仓库根 `.env` 拷到 `%APPDATA%\rts-desktop\`，否则飞书推送/THS 兜底不可用（扫描本身不受影响）。
- Electron 启动时可能打印 `DawnGraphiteCache` 缓存告警——实测与渲染无关，别当故障。

## 6. 部署与回滚要点

- **部署**：单机绿色目录（`win-unpacked/` 整目录 839.7 MB，含自带 Python 与仓库快照），拷走即用，无需安装器；首次启动自动种库建 `m021` 表。
- **回滚**：桌面版对终端扫描器是**纯加法**——回滚 = 删掉 `desktop/` 使用 + 不设 `RTS_LOCAL_PANEL`，终端回到改前行为，无数据迁移需要撤销（`view_snapshot` 表留着无害）。若要回到 `e651fff` 之前的版本，`git revert e651fff` 即可（无 DB 结构性破坏，m021 建表幂等可共存）。
