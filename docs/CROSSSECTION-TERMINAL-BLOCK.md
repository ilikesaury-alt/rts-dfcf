# 横截面异动 · 终端区块规格

> 本文是 `scanner/crosssection.py::format_terminal_block()` 输出的**逐字规格**。
> 目的：让任何实现者（含 AI 分析模块、外部工具、未来的我）不必读源码就能
> 正确解析这一块。**实现变更时必须同改本文**，否则文档说谎。
>
> 最后对齐：2026-11-17（展示改为「持续 / 新进」两组：稳定锚点 + 动静提示）

---

## 1. 这一块是什么

`≡ 横截面异动` 是一个**并列观察层**，不是结论源。它的唯一产物是：

- `crosssection_signal` 表（落库）
- 终端 `≡` 块（打印）

**数据边界（硬性契约）**：本层**只读**自己的环形缓冲与 `crosssection_signal`，
**不读** `appearances` / `offboard_*` / `recommendations` / `market_extra_cache`。
任何违反此契约的改动都是设计事故。

---

## 2. 区块边界与符号约定

终端用三个符号区分层级，`ai_digest/panel.py` 依赖它们切块：

| 符号 | 含义 | 本块用否 |
|---|---|---|
| `◆` | 区标题 | ❌ **本块任何一行都不得以 `◆` 开头** |
| `—` | 段标题 | ❌ **本块任何一行都不得以 `—` 开头** |
| `≡` | 并列观察区块标题 | ✅ 仅首行 |

⇒ 首字符必须是 `≡`。块内其余行一律以**两个半角空格**缩进。

**空串契约**：关闭（`RTS_CROSSSECTION=0`）或非交易时段 ⇒ 返回 `""`（不打印任何东西）。

## 3. 首行（表头）

固定格式，字段全部来自 `health()`：

```
≡ 横截面异动 · HH:MM:SS | 有效 {valid_rows} 只 | 缓冲 {depth}/8 | p95 0.950 | 信号 {signals} | {跨源价差} [| 已剔封板 {n}]
```

### 字段逐项

| 字段 | 来源 | 说明 |
|---|---|---|
| `HH:MM:SS` | `health()["time"]` | 本轮快照墙钟时刻 |
| `有效 {n} 只` | `valid_rows` | **当轮取数成功且通过清洗的创业板只数**（分位分母就是它） |
| `缓冲 {d}/8` | `buffer_depth` | 环形缓冲已填深度，满 8 |
| `p95 0.950` | `CS_P95` 常量 | 复合分位阈值，只留 ≥ 0.95 |
| `信号 {n}` | `signals` | **过完全部过滤后落库/展示的条数** |
| `跨源价差 …` | `divergence` | 见下方三态 |
| `已剔封板 {n}` | `sealed_skipped` | **仅在 n>0 时出现**；剔除必留痕，不静默少票 |

### `跨源价差` 三种形态

```
跨源价差 未校验                    ← divergence is None（榜内票不足，无法比对）
跨源价差 0.32%                     ← 正常
跨源价差 0.32% ⚠超容忍1.0% 最大2.1% ← divergence_ok is False，附最大偏差
```

## 4. 状态行（0 或 1 行，紧跟表头）

按 `state` 分支，**互斥**：

| state | 输出 |
|---|---|
| `throttled` | `  本轮快照节流（沿用上一轮结果，未重新取数）` |
| `no_data` | `  无有效快照（东财取数失败或全市场停牌）` |
| `stale` | `  陈旧轮：上游快照与上轮相同，本轮不产出（累计 N 轮）` |
| 预热中 | `  预热中 {depth}/6（60s 一轮，约 N 分钟后产出）` |
| 正常 | **无此行** |

⚠ 换源雪球后 `native_speed=True` 时**不进入预热分支**（原生 `percent5m` 免预热）。
该分支保留为防御性代码。

## 5. 判据图例行（仅当有信号时出现）

```
  判据：一致性(全正/全负/混合) · 量价(配合/背离/—) · 轮次(当日出现过几轮)
  分组：持续 ≥5轮(最多 5 条) · 新进 本轮首现(最多 3 条) · 中间 2~4 轮不展示
  排序：组内质量(全正·配合 > 全正·— > 其余) → 轮次 → 分位 → 额涌 → 量比
```

### 为什么要分组（2026-11-17）

用户反馈「≡ 区变化太快，眼花缭乱不知道咋选」。实测当日 50 轮 / 756 只票：

- **展示行相邻两轮重疰中位数只有 1/8**（几乎整屏换新）；
- 当日只出现 1 轮的票占 34%（261/756），但反复出现 ≥5 轮的有 180 只、≥10 轮 52 只。

⇒ 稳定子集**确实存在**，只是旧排序把「质量层」放在「轮次」之前，而 1 轮窗口里
「全正·配合」噪声极易达成 ⇒ 稳定票被噪声顶下去。分组只改**展示**：不增删票、
不给方向、不改落库口径；两个上限之和 == `CS_TOP_N`。

三个判据都是**层内自算**，不引入任何外部区域数据：

| 判据 | 取值 | 判定规则 |
|---|---|---|
| **一致性** | `全正` / `全负` / `混合` | `speed_1`、`speed_3`、`speed_5` 三者同号。任一为 `None` 或符号不同 ⇒ `混合` |
| **量价** | `配合` / `背离` / `—` | `amount_surge > 1` 且 `speed_1 > 0` ⇒ `配合`；`amount_surge > 2` 且 `speed_1 <= 0` ⇒ `背离`；其余 ⇒ `—`（与 `_volume_price` 同口径） |
| **轮次** | 整数 | 该票**当日**进入 p95+ 的次数，跨交易日清零。计数发生在**过滤前** |

### 分组码（展示用）

| 取值 | 条件 | 展示 |
|---|---|---|
| 持续 | `轮次 >= CS_PERSIST_MIN(5)` | ✅ 在前，最多 `CS_TOP_PERSIST(5)` 条 |
| 中间 | `2 <= 轮次 < 5` | ❌ 不展示（实测换屏主贡献者，尚未证明持续性） |
| 新进 | `轮次 <= 1` | ✅ 在后，最多 `CS_TOP_NEW(3)` 条（单轮噪声高发） |

## 6. 信号行（两组共最多 `CS_TOP_N = 8` 条）

组标题行（普通续行，不以 `◆`/`—` 起头，不匹配数据行正则）：

```
  持续（当日 ≥5 轮 · {n} 只，先看这组）
  新进（本轮首现 · {n} 只，单轮噪声高发，只看动静）
```

数据行（序号**跨组连续**，1..N）：

```
  {i}. {symbol} {name} {price:.2f} {percent:+.2f}% | 1m {s1} 3m {s3} 5m {s5} | 额涌 {as}× 量比 {vr} 分位 {p:.3f} | {一致性}·{量价}·{轮次}轮
```

### 逐字段样例（真实数据 2026-11-16 13:05）

```
  1. SZ300366 ST创意 5.11 +13.05% | 1m 0.39% 3m 0.39% 5m 1.19% | 额涌 1.32× 量比 10.65 分位 0.999 | 全正·配合·50轮
```

| 字段 | 格式 | 缺值表现 | 含义 |
|---|---|---|---|
| `i` | 1..8 | — | 展示序号（跨组连续；组内按 §8 排序键） |
| `symbol` | `SZ300xxx` | — | 雪球符号，创业板前缀 `SZ300`/`SZ301` |
| `name` | 字符串 | 回退为 symbol | 股票名 |
| `price` | `%.2f` | — | 现价（元） |
| `percent` | `%+.2f%%` | — | **当日**涨跌幅，带符号 |
| `1m` | `%.2f%%` | `—` | 1 分钟涨速（本层环形缓冲差分） |
| `3m` | `%.2f%%` | `—` | 3 分钟涨速（本层差分） |
| `5m` | `%.2f%%` | `—` | 5 分钟涨速（**雪球原生 `percent5m` 优先**，差分兜底） |
| `额涌` | `%.2f×` | `—` | 成交额增量倍数（今轮额 / 前 5 轮均值） |
| `量比` | `%.2f` | `—` | 量比（雪球原生 `volume_ratio`） |
| `分位` | `%.3f` | — | 复合分横截面分位，范围 `[0.950, 1.000]` |
| `一致性` | 中文 | 回退 `混合` | 见 §5 |
| `量价` | 中文 | 回退 `—` | 见 §5 |
| `轮次` | 整数 + `轮` | 回退 1 | 见 §5 |

⚠ **缺值一律 `—`（U+2014），不是 `0.00`。** 二者语义完全不同：
`—` 表示"窗口深度不足尚未能计算"，`0.00` 表示"算了，确实是零"。

## 7. 空信号行

两种情况**文案不同**（不能把「有异动但不够持续」说成「没异动」）：

- 本轮**没有任何** p95+ 信号且已过预热：

```
  （本轮无 p95+ 榜外异动）
```

- 有信号但全落在中间带（2~4 轮），两组都空：

```
  （本轮 {n} 只 p95+ 信号均不足 5 轮，尚未证明持续性，本轮不展示）
```

- 「持续」组空但「新进」有票时，只打一行提示再打新进组：

```
  （本轮无 ≥5 轮持续票）
```

## 8. 排序规则

```
复合分 = 0.35·z(speed_1) + 0.30·z(speed_3) + 0.20·z(amount_surge) + 0.15·z(vol_ratio)
分位   = 严格低于本票的只数 / (n - 1)        ← n = 当轮有效行数，并列取保守侧
展示序 = 展示分组(持续 > 中间 > 新进)
         → 组内质量层(全正·配合 > 全正·— > 其余)
         → 当日轮次 → 分位 → 额涌 → 量比（各键降序，越小越靠前）
```

⚠ **分组先于质量闸**（2026-11-17）：持续组整组排在前面，哪怕某只持续票的
`混合·—`（事后会被 `CS_PERSIST_MIN` 门挡住的那一类不会进展示）。
**同组内**质量闸仍先于轮次与分位。排序键单源 = `scanner.crosssection.signal_sort_key`，
终端 `≡` 块与 AI 素材共用（守卫 `test_crosssection_sort_key_matches_terminal`）。

**三项必须记住的口径**：

1. **z-score 分母是当轮全部有效行**（实测约 1354 只），不是只有异动票。
   所以分位衡量的是"相对全市场有多异常"。
2. **分位不是涨幅排名**。跌得快的票 `speed` 同样是异常高值，照样进榜。
   本层不判方向 —— 这是设计，不是缺陷。
3. **量价 65% 权重在价格速度上**（0.35+0.30），成交额只占 20% ⇒ 本质是"价格速度榜"。

### 过滤顺序（分位之后，按此顺序）

```
1. pct_rank < 0.95          → 丢
2. 在飙升榜内（board）        → 丢（只作跨源校验样本）
3. amount < 3000 万          → 丢（成交额门）
4. 已封涨停                  → 丢 + sealed_skipped 计数
```

**封板判定（层内自足）**：
`prev_close = price / (1 + percent/100)`，`涨停价 = prev_close × 1.20`；
`price >= 涨停价 × 0.985` ⇒ 已封板。
⚠ 创业板**一律 20%（含 ST）**，不是 5%。

## 10. 解析要点（给实现者）

1. **首行用 `·` 分节**，字段名后跟值；建议按 `·` split 后再按 `|` split。
2. **信号行按 `|` 切成 4 段**：`序号+代码+名称+价+涨幅` / `1m 3m 5m` / `额涌 量比 分位` / `判据后缀`。
3. **判据后缀按 `·` split 成 3 项**，第 3 项去掉尾部 `轮`。
4. **块终止条件**：遇到以 `◆` 或 `—` 开头的行、或以单个空格（非两个）开头的行、
   或空行。不要靠"读到文件尾"判断。
5. **不要假设条数**：`CS_TOP_N=8` 是展示上限（持续 ≤5 + 新进 ≤3），实际可能 0~8 条。
6. **组标题行必须被跳过**：`持续（…）` / `新进（…）` / `（本轮无 …）` 都是续行，
   不匹配数据行正则（无 `序号.` 前缀）。解析器**只能**靠正则取行，不得假设
   「块里每行都是数据」（守卫 `test_terminal_block_with_groups_survives_panel_parse`）。

## 11. 与 AI 分析的关系（2026-11-24 起：不进入 AI 分析）

本块照常写进 `logs/panel_md/股票池.md`，终端 / 面板 / 看板 / `crosssection_signal`
一切照旧；但从 2026-11-24 起**不进入 AI 分析**：`ai_digest` 读面板的唯一入口
`panel.load_panel_md()` 会剔除 `≡` 区，AI 只看 `v1 池选` + `沪深飙升` 三段。

`--source crosssection` / `--source all` / `--exclude crosssection` 三个开关、
`crosssection_view.py` 素材层、`llm.SYSTEM_PROMPT_CROSSSECTION` / `..._MERGED`
及 research 提示词里的横截面说明均已移除（反向守卫：
`tests/test_ai_digest_no_crosssection.py`）。

⚠ `panel.parse_panel_text` 仍保留 `≡` 区的解析能力（纯函数，不主动读文件），
但生产链路上不再有消费者；不要据此认为横截面数据仍会喂给模型。
