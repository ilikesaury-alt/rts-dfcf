# 候选池筛选优化修复计划（v2 修正版）

## Summary

基于 38 个交易日、2873 条推荐记录的回测测评，针对"人工选股候选池"场景进行优化。核心目标：**提升候选池中好票的可见度，降低坑人票的误导风险**。

## Current State Analysis

### 候选池生成流程
1. `orchestrator._score_stock` 对每只股票尝试 4 策略
2. `_classify_category` 选最贴合标签，首板票可双挂 new_face + short_term
3. 4 桶独立排序后 `display()` 平铺展示 + 精选专区（Top 2）
4. `save_recommendations` 已有 `(date, symbol, category)` 去重

### 关键问题
- **pullback 大跌率 35.1%**，但与主候选池并列展示无风险区分
- **反指维度**：IC<0 却仍在加分，但需区分"基础评分维度"和"额外加分维度"
  - 基础评分维度（不可清零）：`momentum_volume`(analysis.py:531)、`new_face_bottom`(analysis.py:419)、`_vol_rank_combo_score`(analysis.py:117)
  - 额外加分维度（可安全处理）：`turnover_bonus`(enhancer.py:108)
- **大盘环境** IC=0.214 是最强正信号，但 UI 未显示
- **双挂票** display 显示两次，干扰判断

### v1 方案的不合理之处（已修正）
1. v1 计划清零 `momentum_volume`/`new_face_bottom` 等——这些是策略基础评分，清零会破坏策略逻辑
2. v1 计划修改 `scan_with_raw` 返回值——实际可从 dimensions 直接读取，无需改返回值
3. v1 计划逐只查询历史大跌率——应批量查询
4. v1 遗漏 display 双挂去重

## Proposed Changes

### Change 1: pullback 移到独立高风险区（display.py）

**文件**: `scanner/display.py`

**What**: 将 pullback 从主候选池分离，移到界面末尾"⚠️ 高风险监控"区。

**Why**: pullback 大跌率 35.1%，与主候选池并列展示会误导选股。

**How**:
1. 调整 `display()` 展示顺序：精选 → 新面孔 → 动量延续 → 超短次日 → **⚠️ 高风险监控（pullback）** → 掉榜回顾
2. pullback 区域标题改为：`{ANSI['RED']}⚠️ 高风险监控 — 回调介入（历史大跌率35%，谨慎参考）{ANSI['RESET']}`
3. pullback 行首图标从 `○` 改为 `⚠`
4. 状态栏（display.py:149）的 `回{len(pullback_list)}` 改为红色

### Change 2: 反指维度风险标签（enhancer.py + models.py + display.py）

**文件**: `scanner/models.py`, `scanner/enhancer.py`, `scanner/display.py`

**What**: 对 IC<0 的维度设置风险标签 `risk_flags`，UI 显示⚠️标记。**不清零任何加分**（基础评分维度清零会破坏策略逻辑）。

**Why**: 反指维度仍在加分会推高大跌概率高的票。但基础评分维度（momentum_volume 等）是策略核心，不能清零。折中方案：保留加分，但加风险标签供人工判断。

**How**:
1. **models.py** — `Candidate` 新增字段：
   ```python
   risk_flags: list[str] = field(default_factory=list)
   ```
2. **enhancer.py** — 新增 `_set_risk_flags(c)`，在 `apply_all_bonuses` 末尾调用：
   ```python
   def _set_risk_flags(c: Candidate):
       dims = c.kline.dimensions if c.kline else {}
       # IC<-0.1 的反指维度（基于回测）
       if (dims.get("momentum_volume") or 0) > 0:
           c.risk_flags.append("放量")
       if (dims.get("new_face_bottom") or 0) > 0:
           c.risk_flags.append("底部确认")
       if (dims.get("v_mo_divergence") or 0) != 0:
           c.risk_flags.append("背离")
       if (dims.get("turnover_bonus") or 0) > 0:
           c.risk_flags.append("高换手")
   ```
   注：`momentum_rank_change` 不是独立 dimension，它是 `_vol_rank_combo_score` 的输入，无法单独标记，跳过。
3. **display.py** — `_print_row` 和精选行尾追加风险标签：
   ```python
   if c.risk_flags:
       risk_str = f" {ANSI['RED']}⚠{'/'.join(c.risk_flags)}{ANSI['RESET']}"
   ```

### Change 3: 大盘环境标签显示（display.py）

**文件**: `scanner/display.py`

**What**: 在 display 顶部状态栏显示今日大盘环境（强势/中性/弱势）。

**Why**: `market_env_bonus` IC=0.214 是最强正信号。弱市日候选池命中率显著下降，用户应减少选股。

**How**:
1. **不改 orchestrator 返回值**——`market_env_bonus` 已存入 `c.kline.dimensions["market_env_bonus"]`（enhancer.py:241）
2. `display()` 从 `all_c` 的第一个 candidate 的 dimensions 读取 `market_env_bonus`
3. 顶部状态栏（display.py:149）追加环境标签：
   ```python
   env_bonus = all_c[0].kline.dimensions.get("market_env_bonus", 0) if all_c and all_c[0].kline else 0
   if env_bonus > 0:
       env_tag = f"{ANSI['GREEN']}[大盘强势]{ANSI['RESET']}"

       env_tag = f"{ANSI['RED']}[大盘弱势·谨慎]{ANSI['RESET']}"

   ```

### Change 4: 历史大跌率标签（database.py + orchestrator.py + display.py + models.py）

**文件**: `scanner/database.py`, `scanner/orchestrator.py`, `scanner/models.py`, `scanner/display.py`

**What**: 为候选股标注历史大跌率（近 90 天推荐中次日跌幅≤-5% 的占比）。

**Why**: 评分系统区分度失效，历史大跌率可作为独立风控参考。

**How**:
1. **models.py** — `Candidate` 新增 `hist_loss_rate: float | None = None`
2. **database.py** — 新增**批量查询**函数（单次 SQL）：
   ```python
   def get_loss_rates_batch(conn, symbols, lookback_days=90):
       """批量返回 {symbol: loss_rate}，样本<3 不包含。"""
       if not symbols:
           return {}
       placeholders = ",".join("?" * len(symbols))
       cur = conn.execute(
           f"SELECT symbol, COUNT(*), SUM(CASE WHEN next_day_pct <= -5 THEN 1 ELSE 0 END) "
           f"FROM recommendations WHERE symbol IN ({placeholders}) "
           f"AND next_day_pct IS NOT NULL AND date >= date('now', ?) "
           f"GROUP BY symbol", (*symbols, f"-{lookback_days} days"))
       return {row[0]: row[2] * 100 / row[1] for row in cur if row[1] >= 3}
   ```
3. **orchestrator.py** — `scan_with_raw` 中 `apply_all_bonuses` 后调用批量查询，存入 candidate：
   ```python
   syms = {c.stock.symbol for c in all_candidates}
   loss_rates = get_loss_rates_batch(conn, list(syms))
   for i, c in enumerate(all_candidates):
       rate = loss_rates.get(c.stock.symbol)
       if rate is not None:
           all_candidates[i] = dataclass_replace(c, hist_loss_rate=rate)
   ```
4. **display.py** — `_print_row` 中，若 `hist_loss_rate >= 25`，行尾追加 `[历史大跌率{X}%]`

### Change 5: display 双挂去重（display.py）

**文件**: `scanner/display.py`

**What**: 双挂票（new_face + short_term）在 display 中只在评分最高的桶显示一次。

**Why**: 避免同一只票显示两次干扰判断。

**How**:
1. `display()` 开头构建已显示 symbol 集合 `displayed_syms: set[str] = set()`
2. 各桶展示时，跳过已在集合中的 symbol：
   ```python
   for c in new_faces:
       if c.stock.symbol in displayed_syms:
           continue
       displayed_syms.add(c.stock.symbol)
       _print_row(c, icon=icon)
   ```
3. 展示顺序决定优先级：精选 → 新面孔 → 动量 → 超短 → pullback。先展示的桶保留，后展示的桶跳过重复。

## Assumptions & Decisions

1. **不清零基础评分维度加分**：`momentum_volume`/`new_face_bottom`/`_vol_rank_combo_score` 是策略核心评分，清零会破坏候选池生成。仅加风险标签。
2. **额外加分维度（turnover_bonus）也暂不清零**：保持评分系统稳定性，先观察风险标签效果。
3. **old_face 无需处理**：已于 2026-06-10 移除。
4. **大盘环境仅显示不门禁**：保留用户决策权。
5. **双挂去重优先级**：new_face > short_term（首板票先在新面孔展示，超短列表跳过）。
6. **历史大跌率门槛**：样本<3 不显示，大跌率≥25% 才标注。
