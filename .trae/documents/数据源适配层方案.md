# 数据源适配层修改方案

## Summary（摘要）

抽象 `DataSourceAdapter` 接口，在保留雪球为主数据源的前提下，引入 AKShare 作为兜底数据源。当雪球反爬封禁、`make_session` 失败或单接口持续失败时，系统自动降级到 AKShare，避免单点依赖导致的整体瘫痪。**AKShare 作为可选依赖**（lazy import，未安装不影响雪球模式），最小侵入现有代码。

---

## Current State Analysis（当前状态分析）

### 数据源耦合现状

`scanner/api.py` 中 **7 个核心函数全部硬编码雪球 URL**：

| 函数 | 雪球接口 | 调用方 | 失败影响 |
|---|---|---|---|
| `make_session()` | `xueqiu.com/hq`（获取 cookie） | `unified_scanner.py:52` | **整体瘫痪**（单点故障） |
| `fetch_biaosheng()` | `hot_stock/new_list`（飙升榜） | `unified_scanner.py:80` | 无候选股，跳过本轮 |
| `fetch_xueqiu_hot_list()` | `hot_stock/list`（热搜榜） | `unified_scanner.py:86` | 双榜校验失效（可降级） |
| `fetch_kline()` | `chart/kline.json` | `orchestrator.py:124`, `tracker.py:231` | 已有 stale_cache 兜底 |
| `fetch_market_caps_batch()` | `batch/quote.json` | `orchestrator.py:447`, `tracker.py:80`, `unified_scanner.py:115` | 小而美规则失效 |
| `fetch_market_index()` | `chart/kline.json`（SZ399006） | `orchestrator.py:534` | 市场环境分缺失 |
| `_fetch_minute_data()` | `chart/minute.json` | `analyze_opening_strength`/`analyze_intraday`/`estimate_live_volume` | intraday/opening 缺失（已有降级） |

### 现有容错机制

- **熔断器**：`fetch_biaosheng`/`fetch_xueqiu_hot_list` 各有独立熔断器（连续 3 次失败熔断 60-600s + 缓存兜底）
- **K 线 stale_cache**：`fetch_kline` 失败返回 DB 缓存；`orchestrator._fetch_all_klines` 有 `stale_cache` 字典兜底
- **限流处理**：`_request_with_retry` 处理 429（Retry-After）+ 5xx 指数退避
- **全局节流**：`_throttle(min_interval=0.15)` 控制请求频率

### 关键风险点

1. **`make_session()` 失败无兜底**：雪球反爬升级时 cookie 获取失败，`unified_scanner.py:52` 直接抛异常，整个扫描器无法启动
2. **无跨数据源降级**：所有熔断/缓存都在雪球内部，雪球整体不可用时无备选
3. **AKShare 未引入**：`requirements.txt` 仅 `requests` + `wcwidth`，无任何备选数据源依赖

## Proposed Changes（提议的变更）

### 1. 新增 `scanner/data_source.py`（核心，~250 行）

**职责**：定义统一适配器接口 + 雪球/AKShare 双实现 + 工厂函数

**接口定义**（与现有 api.py 函数签名对齐，去掉 session 参数）：

```python
class DataSourceAdapter(Protocol):
    name: str
    def fetch_kline(self, symbol: str, days: int = 15) -> list[dict] | None: ...
    def fetch_biaosheng(self, size: int = 100) -> list[dict]: ...
    def fetch_hot_list(self, size: int = 100) -> list[dict]: ...
    def fetch_market_caps_batch(self, symbols: list[str]) -> dict[str, dict]: ...
    def fetch_market_index(self) -> float | None: ...
    def is_available(self) -> bool: ...
```

**XueqiuAdapter**（包装现有 api.py，零改动 api.py）：
- 构造时接收 `session: requests.Session`
- `is_available()`：尝试 `make_session()` 或检查 session 活性
- 内部直接委托 `api.fetch_kline(self.session, ...)` 等

**AkshareAdapter**（兜底实现，lazy import akshare）：
- `is_available()`：`import akshare` 成功即 True
- `fetch_kline()`：调 `ak.stock_zh_a_hist(symbol, period="daily", adjust="qfq")` → 转换为雪球格式 `{timestamp, date, open, high, low, close, volume, percent}`
- `fetch_market_caps_batch()`：调 `ak.stock_zh_a_spot_em()` → 过滤 symbols → 字段映射 `{market_cap, circ_market_cap, turnover_rate, current, percent}`
- `fetch_market_index()`：调 `ak.stock_zh_index_spot_em()` → 过滤 399006 → 返回涨跌幅
- `fetch_biaosheng()`/`fetch_hot_list()`：返回空列表 + 警告日志（AKShare 无语义对齐的榜单接口，让现有熔断+缓存兜底）
- **符号格式转换**：雪球 `SZ300001` ↔ AKShare `300001`（内部处理）

**FallbackAdapter**（组合，自动降级）：
- 构造时接收 `[primary, secondary]` adapter 列表
- 每个方法调用：先试 primary，失败或返回空 → 试 secondary
- 记录降级事件到日志（便于排查雪球故障）

**工厂函数 `get_adapter()`**：
- 读 `config.DATA_SOURCE`（`"auto"` / `"xueqiu"` / `"akshare"`）
- `"auto"`（默认）：返回 `FallbackAdapter([XueqiuAdapter, AkshareAdapter])`
- `"xueqiu"`：仅 `XueqiuAdapter`（向后兼容）
- `"akshare"`：仅 `AkshareAdapter`（调试/雪球全挂时强制）
- 单例缓存（避免重复 `make_session`）

## Assumptions & Decisions（假设与决策）

### 关键决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | **AKShare 作为可选依赖**（lazy import） | 不破坏现有部署；未安装时自动降级为仅雪球模式 |
| D2 | **飙升榜/热搜榜不做 AKShare 兜底** | AKShare 无语义对齐的榜单接口；让现有熔断+缓存兜底，避免引入语义不对齐的数据污染候选池 |
| D3 | **不改 api.py 内部实现** | XueqiuAdapter 包装现有函数，保持向后兼容；降低改动风险 |
| D4 | **去掉 orchestrator._fetch_all_klines 的 ThreadPoolExecutor** | AKShare 非线程安全（内部用 requests + pandas）；adapter 层改为串行调用。性能影响可接受（原 8 并发 → 串行，但 K 线有 120s TTL 缓存） |
| D5 | **分钟数据不做兜底** | AKShare 的 `stock_zh_a_minute` 与雪球字段差异大且延迟高；intraday/opening_strength 已有 None 降级 |
| D6 | **符号格式由 adapter 内部转换** | 雪球 `SZ300001` ↔ AKShare `300001`；调用方无感知 |

### 假设

- AKShare `stock_zh_a_hist` 返回的 DataFrame 列名稳定（`日期, 开盘, 收盘, 最高, 最低, 成交量, 成交额, 振幅, 涨跌幅, 涨跌额, 换手率`）
- AKShare `stock_zh_a_spot_em()` 返回的 DataFrame 包含 `代码, 名称, 最新价, 涨跌幅, 总市值, 流通市值, 换手率` 列
- AKShare 免费接口的反爬强度低于雪球（AKShare 走东财/新浪公开接口，无 cookie 依赖）

### 不做的事

- ❌ 不引入 tushare（需付费 token，违反"降低运行风险"的轻量原则）
- ❌ 不做 Web UI（不在本次范围）
- ❌ 不改熔断器/缓存逻辑（现有逻辑已成熟，adapter 层只负责数据源切换）
- ❌ 不改字段格式（adapter 输出必须与现有 api.py 输出格式 1:1 对齐，避免下游改动）
